# Brand Strategy Hub — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md` §9 (приложения без классического
`connect_*` к внешнему сервису). Целевой пользователь: бренд-стратег/маркетолог,
формализующий позиционирование бренда (миссия, tone of voice, визуальная система).

## 1. "Credential type" — его нет
Нет `connect_*`. Первое реальное действие — `create_brand_profile` (создать профиль
бренда с нуля) — это internal hub-приложение без внешнего аккаунта.

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` с прямым CTA "Создать профиль бренда" — форма сразу
   в центре, без придуманного шага "подключения", которого структурно нет.
2. **Форма создания профиля** — миссия/vision/value proposition/tone of voice, с
   контекстными плейсхолдерами-примерами (не пустые поля "введите миссию" без
   ориентира, а короткий пример на 1 предложение серым текстом).
3. **После создания профиля** — сразу предложить следующий логичный шаг: определить
   target segments (`create_target_segment`) — цепочка действий видна, не тупик "профиль
   создан, дальше сами разбирайтесь".
4. **Visual Brand System** — отдельный, явно обозначенный поток (draft → activate)
   с понятной иерархией версий — не смешивать с текстовым профилем бренда в одном
   экране.
5. **Multi-brand** — если у агентства несколько брендов клиентов — список профилей с
   быстрым переключателем, сортировка по недавней активности.
